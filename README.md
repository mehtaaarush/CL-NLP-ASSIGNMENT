# LSTM Practice Questions

Worked solutions to the LSTM practice assignment.

- [AarushMehta_500119496.pdf](AarushMehta_500119496.pdf): full working for all five questions
- `verify_solutions.py`: recomputes every numerical answer and checks Q1 and Q2 against PyTorch's `nn.LSTM`
- `build_pdf.py`: generates the PDF

Topics covered: the LSTM forward pass, parameter counting, vanishing gradients, sliding-window
time series preparation, and classification metrics.
